# Contributing to aspirin.app

Thank you for your interest. aspirin.app is in development, and feedback is welcome.

## Where to write

| Repository | What it is | How to contribute |
| --- | --- | --- |
| [responsible-ai](https://github.com/aspirinapp/responsible-ai) | How the AI is designed and the rules we follow | Open an issue with questions or suggestions |
| [aspirin-website](https://github.com/aspirinapp/aspirin-website) | Source of the aspirin.app website | Open an issue for typos, broken links or translation fixes |
| [brand-assets](https://github.com/aspirinapp/brand-assets) | Official logos, colours and images | Issues are closed here. Email [info@aspirin.app](mailto:info@aspirin.app) |
| [.github](https://github.com/aspirinapp/.github) | Organisation profile and community files | Issues are closed here. Email [info@aspirin.app](mailto:info@aspirin.app) |

For partnerships, funding or anything else, email [info@aspirin.app](mailto:info@aspirin.app).

## Issues

- Search existing issues before you open a new one.
- One topic per issue, with a clear title.
- Write in English if you can. Other languages of the website (German, Spanish, French, Ukrainian) are fine too.
- Never include real personal or medical data. Use made-up examples.
- Do not ask for medical advice in issues. Talk to a doctor or pharmacist.

## Pull requests

- Small pull requests are welcome, for example a typo, a broken link or a better translation.
- For bigger changes, open an issue first so we can agree on the approach.
- Keep each pull request focused on one change.

## Please also read

- [Security policy](SECURITY.md): report vulnerabilities privately, never in public issues
